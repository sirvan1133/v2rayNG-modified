# v2.7.8

## English

### Light theme fixes

- Fixed light-mode contrast, colors, configuration cards, vector map, widgets, menus, and popup presentation.
- Fixed tool menus leaving the visible screen on smaller displays or near the bottom edge.
- Fixed inconsistent menu sizing and configuration-card visibility in light mode.

### Added and improved features

- Added a live Persian calendar with daily occasions and official holidays from Bahesab.
- Added adaptive calendar height and red highlighting for official holidays.
- Added a smooth once-per-day drawer scroll hint.
- Added compact, responsive Add and configuration menus with borderless fade-out cards.
- Added haptic feedback for the VPN toggle, Add button, configuration menus, and tool actions.
- Improved live direct ping, Auto Connect, background battery behavior, map recovery, weather, and market widgets.

For most modern Android phones, download **arm64-v8a**. Use **universal** only if you are unsure about your device architecture.

## فارسی

### رفع باگ‌های تم سفید

- اصلاح کنتراست، رنگ‌ها، کارت کانفیگ‌ها، نقشه برداری، ویجت‌ها، منوها و پنجره‌ها در حالت روشن.
- رفع بیرون‌زدگی منوی ابزارها در نمایشگرهای کوچک و کانفیگ‌های نزدیک پایین صفحه.
- اصلاح اندازه منوها و خوانایی کارت‌های کانفیگ در تم سفید.

### امکانات اضافه‌شده و بهبود‌یافته

- اضافه‌شدن تقویم زنده فارسی با مناسبت‌ها و تعطیلی‌های رسمی روزانه از «با حساب».
- تنظیم هوشمند ارتفاع تقویم و قرمزشدن تعطیلی‌های رسمی.
- اضافه‌شدن راهنمای اسکرول نرم منوی همبرگری، روزی یک‌بار.
- اضافه‌شدن منوهای کوچک و واکنش‌گرا برای «+» و سه‌نقطه با کارت‌های بدون کادر و محوشونده.
- اضافه‌شدن بازخورد لرزشی برای کلید VPN، دکمه «+»، سه‌نقطه کانفیگ‌ها و ابزارها.
- بهبود پینگ زنده مستقیم، اتصال خودکار، مصرف باتری پس‌زمینه، بازیابی نقشه، هواشناسی و قیمت ارز.

برای بیشتر گوشی‌های اندرویدی جدید نسخه **arm64-v8a** مناسب است. اگر معماری گوشی را نمی‌دانید، نسخه **universal** را دانلود کنید.
